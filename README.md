# UAE Healthcare Ecosystem Explorer

An interactive, evidence-driven map of how healthcare, insurance, claims, digital health, operations and AI layers connect across the UAE.

## What this project demonstrates

- Systems-level understanding of the UAE healthcare ecosystem
- Interactive exploration across five views
- Abu Dhabi, Dubai and Northern Emirates context
- Healthcare, insurance, claims, digital-health, payment and technology relationships
- English / Arabic navigation
- Evidence-aware framing with explicit limitations where verification is incomplete

## Views

1. National Overview
2. Abu Dhabi
3. Dubai
4. Northern Emirates
5. Value & Opportunity

## Evidence discipline

The Explorer is a professional proof-of-work artifact, not an official regulatory database. Roles, relationships, weights and opportunity framing are simplified for analytical use. Claims should be verified against the relevant UAE regulator or primary source before being used for compliance, legal or operational decisions.

## Run locally

Open `index.html` in a modern browser. The project is intentionally lightweight and does not require a build system or package installation.

## GitHub Pages

The repository is structured so the root `index.html` can be served directly by GitHub Pages.

## Project documentation

See `docs/redesign-corrections-report.md` for the external record of redesign, corrections, accessibility, print/PDF and QA work. Those notes are intentionally kept outside the Explorer interface.

## Data posture

Data is presented with care around the distinction between confirmed regulatory requirements, platform capabilities, public announcements, industry practice and strategic opportunity. Unverified implementation details are not presented as confirmed facts.
